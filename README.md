# P1 - Mobile Development 1

Flutter Training - TaskFlow

TaskFlow is one application that evolves across the course. Each session adds to the same app instead of keeping multiple full app copies.

## Current App

The runnable TaskFlow app lives in:

```text
lib/main.dart
lib/models/
lib/screens/
lib/widgets/
```

## Isolated Examples

Small learning examples live in:

```text
lib/examples/session_01/
lib/examples/session_02/
```

Session 1 covers Flutter and Dart foundations, widgets, layouts, and static UI.

Session 2 covers the Task model, `ListView.builder`, reusable widgets, navigation, and passing data between screens.

## Run

```bash
flutter pub get
flutter run
```

Later sessions continue the same TaskFlow app. Git session tags will be added only after each checkpoint is verified.
